# ColabBridge

### Google Colab Resources from Your Local VS Code

ColabBridge connects your **local VS Code environment** to a **Google Colab runtime** using **SSH and a temporary public tunnel**.

It allows you to write and manage your code from VS Code while using the computational resources of Google Colab.

---

## 🔗 How It Works

```text
┌──────────────────────┐
│    Local Computer    │
│                      │
│        VS Code       │
└──────────┬───────────┘
           │
           │ SSH
           ▼
┌──────────────────────┐
│    Public Tunnel     │
│       Pinggy         │
└──────────┬───────────┘
           │
           │ TCP
           ▼
┌──────────────────────┐
│     Google Colab     │
│                      │
│   CPU • RAM • GPU    │
│   Storage • Python   │
└──────────────────────┘
````

ColabBridge uses the Colab notebook to configure the remote SSH environment and create a temporary SSH endpoint.

You then use the generated **Host** and **Port** in your local VS Code SSH configuration.

---

## ✨ Benefits

* 🖥️ Use **VS Code** as your development environment
* 🎮 Utilize available **Google Colab GPU** resources
* 🧠 Use Colab's **RAM and CPU**
* 💾 Access the Colab runtime's temporary storage
* 🐍 Work with the remote Python environment
* 🔧 Use VS Code's terminal, debugger, extensions, and Git workflow
* 🚀 Convenient for AI/ML, Deep Learning, and experimentation

---

## ⚠️ Limitations

* ⏳ The Colab runtime is temporary.
* 🌐 The SSH tunnel is temporary.
* 🔄 The generated SSH **Host and Port may change** when a new tunnel is created.
* ⏱️ The free Pinggy tunnel has a limited session duration.
* 💾 Files stored only in the temporary Colab runtime may be lost when the runtime is reset or disconnected.
* 🔐 This setup is intended for development and experimentation, not production workloads.

# 🚀 How to Use

## 1️⃣ Run the Colab Notebook

Open:

```text
colab_vscode_remote_ssh.ipynb
```

in **Google Colab**.

Run the notebook **from top to bottom**.

The notebook handles the complete SSH and tunnel setup for you.

At the end, it will provide the connection information similar to:

```text
Host: xxxxx.run.pinggy-free.link
Port: 12345
```

> **Important:** Keep the notebook's tunnel cell running while using VS Code.

---

## 2️⃣ Configure VS Code Remote-SSH

On your local computer, open your SSH configuration file.

### Windows

```text
C:\Users\<YOUR_USERNAME>\.ssh\config
```

### Linux / macOS

```text
~/.ssh/config
```

Add the **Host** and **Port** provided by the Colab notebook:

```sshconfig
Host colab
    HostName <PINGGY_HOST>
    Port <PINGGY_PORT>
    User colab
```

For example:

```sshconfig
Host colab
    HostName xxxxx.run.pinggy-free.link
    Port 12345
    User colab
```

> Replace `<PINGGY_HOST>` and `<PINGGY_PORT>` with the exact values generated by your current Colab session.

---

## 3️⃣ Connect from VS Code

Open **VS Code**.

Press:

```text
Ctrl + Shift + P
```

Select:

```text
Remote-SSH: Connect to Host
```

Then select:

```text
colab
```

VS Code will establish the SSH connection to your Google Colab runtime.

---

## 🎉 4️⃣ Enjoy!

You are now connected:

```text
Local VS Code
      ↓
   SSH Tunnel
      ↓
 Google Colab
      ↓
CPU • RAM • GPU • Storage
```

You can now **develop in VS Code and execute your code using the Colab runtime resources**.
