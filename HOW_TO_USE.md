# How to Use

## 1. Run the Colab Notebook

Run all cells in:

```text
colab_vscode_remote_ssh.ipynb
```

After running, you will get SSH details like:

```text
Host: xxxxx.run.pinggy-free.link
Port: 12345
```

## 2. Extract Host and Port

Example:

```text
Host: mykwn-34-46-137-118.run.pinggy-free.link
Port: 41917
```
## 3. Install Extension
Install the **Remote - SSH** extension in VS Code.

## 4. Configure SSH

Open the SSH config file:

```text
C:\Users\<your_user_name>\.ssh\config
```

Add:

```ssh-config
Host colab
    HostName mykwn-34-46-137-118.run.pinggy-free.link
    Port 41917
    User colab
    PreferredAuthentications password
    PubkeyAuthentication no
    KbdInteractiveAuthentication yes
```

Replace `HostName` and `Port` with the values generated by Colab.

## 5. Connect from VS Code

1. Open **Remote Explorer**.
2. Select **colab**.
3. Choose **Continue**.
4. Select **Linux** if prompted.
5. Enter the password:

```text
colab123
```

## 6. Done

VS Code is now connected to the Colab runtime.

You can run your code from VS Code using the **Colab GPU, RAM, and storage**.
